# Plantilla de prototipo (Phaser 4 + Vite)
1. Copia la plantilla: `cp -r template games/<nombre>` (sin `node_modules`).
2. Entra en la carpeta: `cd games/<nombre>` y ejecuta `npm install`.
3. Arranca: `npm run dev -- --host` (añade `--host` para probar desde el móvil).
4. Abre en el móvil, en la misma wifi, la URL `Network:` que muestra Vite.
